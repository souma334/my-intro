# ハルトのポートフォリオ & 化石発掘ゲーム

ハルトの自己紹介ページと、ブラウザで遊べる「化石発掘ゲーム（ミニゲーム）」を含むプロジェクトです。

## プロジェクトの内容

### 1. ポートフォリオサイト
**ファイル:** `index.html`, `style.css`, `script.js`
- ハルトのプロフィール、興味のある分野（模型制作やゲーム制作）、AIに対する考え方などをまとめたWebサイトです。
- リッチなグラスモーフィズムデザインやスムーズなスクロールアニメーションを実装しています。

### 2. 化石発掘ゲーム
**ファイル:** `fossil.html`, `fossil.css`, `fossil.js`, 各種画像(`fossil_*.png`)
- ポートフォリオの「ゲーム制作」セクションから遊べるブラウザベースのミニゲームです。
- 『ポケットモンスター ダイヤモンド・パール』の地下通路や『化石ホリダー』をモチーフに制作しました。

#### ゲームの特徴と遊び方
- **ピッケル**: 1マスを深く掘ります（壁ダメージ：小）。
- **ハンマー**: 3×3マスの広い範囲を浅く掘ります（壁ダメージ：大）。
- **X線**: 5×5マスの範囲をスキャンし、化石が隠れているマスを一瞬だけフラッシュさせて位置を探ります（壁ダメージ：中）。
- 壁のダメージ（上部の崩壊ゲージ）が限界に達する前に、地中に隠された「頭蓋骨」「あばら骨」「鋭い爪」などの化石をすべて完全に露出させるとクリアです。

## 開発・実行方法

1. このリポジトリのフォルダをVS Code等のエディタで開きます。
2. 拡張機能「Live Server」などを使用して、`index.html` または `fossil.html` をブラウザで起動してください。
3. 特別なビルド環境やサーバーは不要で、そのままブラウザ上で動作します。

## 使用技術
- HTML5 / CSS3 (CSS Grid, Keyframe Animationなど)
- Vanilla JavaScript (フレームワークなし)
- 画像生成AI（ゲーム内の化石アセットとして使用）
